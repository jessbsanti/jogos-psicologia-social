ALTERAÇÕES DESTA VERSÃO

1. O jogo continua com 3 participantes por grupo.
2. Cada aluno digita um código de grupo antes de começar.
3. O oTree reúne somente alunos com o mesmo código.
4. O grupo começa quando 3 pessoas com o mesmo código estiverem conectadas.
5. Ao final da 10ª rodada, aparece um resumo das rodadas:
   - consenso por rodada;
   - alternativa consensual, quando houver;
   - tempo do grupo por rodada;
   - total de consensos;
   - tempo médio.
6. O botão final baixa os dados completos do grupo em CSV.

IMPORTANTE
- Crie uma sessão com o total de participantes esperado.
- O total deve ser múltiplo de 3.
- Oriente cada trio a usar exatamente o mesmo código, por exemplo A1, A2, A3.
- Códigos são convertidos automaticamente para letras maiúsculas.
- Não use o mesmo código para dois trios diferentes.
